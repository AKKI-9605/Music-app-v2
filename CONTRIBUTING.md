# Contributing to Music-app-v2

First off, thank you for considering contributing to AKKI Studio! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please create a new Issue on GitHub. Include:
* Your operating system and browser version.
* A clear description of what is broken.
* Steps to reproduce the bug.

### 2. Suggesting Enhancements
Have an idea for a cool new visualizer or an audio tweak? Open an Issue and tag it as an "enhancement". Explain how it works and why it would be useful for the player.

### 3. Submitting Code Changes (Pull Requests)
If you want to fix a bug or add a feature yourself, follow these steps:
1. **Fork** the repository.
2. Create a new branch for your feature: `git checkout -b feature/my-cool-feature`
3. Make your changes in `index.html`. Keep the vanilla JS clean and avoid adding external heavy libraries unless strictly necessary.
4. Commit your changes: `git commit -m "Add some cool feature"`
5. Push to the branch: `git push origin feature/my-cool-feature`
6. Open a **Pull Request** and describe your changes.

## Development Rules
* **Keep it Local:** Do not add APIs, cloud databases, or backend services. This app is designed to run 100% locally in the browser.
* **Keep it Lightweight:** Prefer vanilla JavaScript over frameworks.
* **Preserve the UI:** Ensure new features match the existing dark, glassmorphic design system.

Thank you for helping make AKKI Studio better!
